# Casa Cristalina

Site institucional da Casa Cristalina, importadora e distribuidora brasileira de utilidades domésticas.

## Publicação

O projeto é estático e pode ser publicado diretamente no GitHub Pages ou Cloudflare Pages. No Cloudflare Pages, use a pasta raiz do projeto como diretório de saída e não defina comando de build.
